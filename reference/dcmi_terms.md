# Get names of DCMI terms

The Dublin Core Metadata Initiative defines a set of terms at
<https://www.dublincore.org/specifications/dublin-core/dcmi-terms/>.

## Usage

``` r
dcmi_terms(term = NULL)
```

## Arguments

- term:

  If specified, match term to official DCMI nomenclature, and return
  single match.

## Value

A character vector of DCMI terms.
